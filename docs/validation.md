# 검수 범위와 예제 결과

이 기록은 저장소에 포함한 예제와 도구의 확인 범위를 설명한다. 자동 검사 통과와 실제 수업의 이해도·실습 성공은 구분한다.

## 다시 확인하기

저장소 루트에서 실행한다.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tools/tests -v
python tools/check_examples.py
python tools/build_network_diagrams.py --out build/diagrams
```

마지막 명령에는 한글 글꼴이 필요하다. [그림 도구 안내](diagrams.md)를 참고한다. 검사 로그와 HTML 미리보기는 `build/day3/`에 생성되며 Git에는 포함하지 않는다.

## 공유본 준비 시 확인한 결과

로컬 macOS·Python 3.9.6 환경에서 다음을 확인했다. 새 환경에서는 Python 3.10 이상을 권장한다. GitHub 자동 검사 설정은 Ubuntu·Python 3.10/3.12에서 단위 테스트와 예제 검수를 실행한다. 실제 실행 결과는 저장소의 Actions에서 확인한다.

- 단위 테스트 33개 통과: 용어 검사 23개, 교안 렌더링·문체 검사 5개, 그림 생성기 5개.
- 예제 6개의 구조 검사·Markdown 변환·하네스·린터·HTML 생성 완료.
- 용어 항목 170개와 Python 실행 예제 7개 통과.
- PNG 19개·SVG 19개·전체 그림 미리보기 1개를 실제 생성하고 재실행했다. PNG 파일 유효성과 SVG 구문을 확인했다.
- 스킬 메타데이터 검사 통과. 개인 로컬 경로·인증 토큰·실제 Notion 페이지 및 업로드 식별자가 공유 파일에 남지 않았는지 확인했다.

| 교시 | 하네스 PASS | FAIL | SKIP | 린터 ERROR | WARN |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 | 32 | 0 | 1 | 0 | 2 |
| 2 | 16 | 0 | 1 | 0 | 2 |
| 3 | 33 | 0 | 1 | 0 | 2 |
| 4 | 39 | 0 | 1 | 0 | 0 |
| 5 | 32 | 0 | 1 | 0 | 0 |
| 6 | 25 | 0 | 3 | 0 | 2 |

PASS 수에는 용어 항목과 실행 출력 비교가 함께 포함된다. SKIP 8개는 Python 실행 대상이 아닌 명령·실습 블록이다. Windows 명령이나 Packet Tracer 실습이 성공했다는 뜻은 아니다.

## 남아 있는 WARN의 의미

1·2·3·6교시에는 각각 ‘실행 코드 블록 수가 기준보다 적음’과 ‘함정·에러 시연 횟수가 기준보다 적음’이 표시된다. 린터의 기본 기준은 코딩 수업을 전제로 한다. 이 예제는 네트워크 개념, 조회 결과 해석과 관찰 활동도 포함하므로 코드 블록 수만으로 활동량을 판단하지 않는다.

이 8개 WARN은 예제의 성격에 따른 검토 대상으로 남겼다. 새 교안에서도 같은 경고를 일괄 무시하지 말고, 수업 시간에 맞는 활동량과 실패 결과를 해석하는 기회가 충분한지 읽고 판단한다. 구조 오류·하네스 FAIL·린터 ERROR는 해결한 뒤 사용한다.

## 별도로 확인할 것

- 용어 검사는 `learning_terms`에 등록한 항목만 검사한다. 새 용어 누락, 어려운 정의, 같은 문단 안의 세부 설명 순서는 사람이 읽어 확인한다.
- 그림의 `text_content`는 실제 그림 레이블과 일치해야 한다. 메타데이터만 고쳐 검사를 통과시키지 않는다.
- Python 하네스는 교안 코드를 실제 실행한다. 출처를 신뢰할 수 있는 교안에 사용한다.
- DNS 실제 응답은 시간과 접속 환경에 따라 달라질 수 있다. Windows 명령과 Packet Tracer 동작은 사용할 수업 환경에서 직접 확인한다.
- 그림은 macOS의 한글 글꼴로 확인했다. Windows·Linux 및 다른 글꼴의 실제 화면은 별도 확인이 필요하다. 글자 폭에 따라 줄바꿈과 배치를 조정한다.
- Notion 업로드와 저장 후 비교는 사용자의 Notion 연결에서 수행한다. 로컬 HTML 검수가 Notion에 저장된 결과의 검수를 대신하지 않는다.

최종 읽기 검수에는 [검수 기준](../tools/judge_checklist.md)과 [스킬의 발행 절차](../.agents/skills/lesson-page/references/validation-and-publishing.md)를 함께 사용한다.
