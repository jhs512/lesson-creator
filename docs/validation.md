# 검수 범위와 예제 결과

이 기록은 저장소에 포함한 예제와 도구의 확인 범위를 설명한다. 자동 검사 통과와 실제 수업의 이해도·실습 성공은 구분한다.

## 다시 확인하기

저장소 루트에서 실행한다.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tools/tests -v
python tools/check_examples.py
python tools/build_network_diagrams.py --out build/diagrams
```

마지막 명령에는 한글 글꼴이 필요하다. [그림 도구 안내](diagrams.md)를 참고한다. 검사 로그와 HTML 미리보기는 `build/day3/`에 생성되며 Git에는 포함하지 않는다.

## 2026-09-06 교시 역할 재구성 후 확인한 결과

사용자 요청에 따라 1–3교시는 자세한 개념 설명, 4–5교시는 따라 하는 실습과 설명, 6교시는 한 프로젝트로 이어지는 종합실습으로 바꿨다. 제작 순서는 개념 그림 8개 → 전체 교안 → 실측 준비였다. 마지막 단계의 실제 촬영은 사용자가 PC에서 이어가겠다고 하여 보류했다.

- 단위 테스트 50개 중 49개 통과, 설치된 한글 글꼴 자동 검색에 의존하는 기존 검사 1개 건너뜀. 새 그림 8개는 별도 지정한 Nanum Gothic으로 실제 생성하고 이미지로 검토했다.
- 6개 JSON의 구조 검사, Markdown·HTML 생성, 하네스·역할별 린터 실행 완료. 하네스 FAIL 0, 린터 ERROR 0.
- 실제 본문에 맞게 용어 항목 154개를 선언했다. 개념 교시의 실습 코드를 개념 설명으로 교체하고 종합실습을 다시 설계했으므로 이전 버전의 모든 예제를 보존했다고 보고하지 않는다. 이전 내용과 그림 원본은 Git 이력에 남는다.
- 개념 그림 8개와 실습 설명용 구성도 7개, 본문 그림 총 15개의 PNG·SVG·실제 글자 메타데이터를 대조했다.
- 독립 읽기 검수에서 나온 종합실습 대체 준비의 중간 종료 안내를 수정했고, 캐시 그림의 IP가 DNS 서버 주소로 오해되지 않도록 ‘저장된 A’와 ‘원본 A’ 레이블을 붙였다.
- 기존 스킬 메타데이터 검사 통과. 역할별 과제 기준, 실제 번호 목록, 캡처 근거, 비코드 종합실습 해설을 위한 회귀 검사 8개를 추가했다.
- Notion의 표지와 교시 6개에 반영한 뒤 저장 내용을 다시 조회했다. 저장 서식의 이스케이프·공백·이미지 URL 차이를 정규화한 본문 대조와 저장본 린터 ERROR 0을 확인했다. 표지의 하위 교시 참조 6개, 이미지 15개, 보충·정답 토글 18개가 의도한 위치와 순서로 남았다. 앱 화면을 직접 연 시각 검수와는 구분한다.

### 실제 촬영은 다음 작업

현재 실행 환경에서는 Packet Tracer를 실행하지 않았다. 사용자 요청에 따라 4–5교시 실제 화면 촬영은 PC 사용 가능 시점까지 보류했다. `.pkt` 파일과 실제 캡처를 만들었다고 보고하지 않는다. [촬영 계획](packet-tracer-capture-plan.md)의 장면을 실제 버전에서 재현한 뒤 명령·UI·예상 결과도 함께 확인한다.

## 별도로 확인할 것

- 용어 검사는 `learning_terms`에 등록한 항목만 검사한다. 새 용어 누락, 어려운 정의, 같은 문단 안의 세부 설명 순서는 사람이 읽어 확인한다.
- 그림의 `text_content`는 실제 그림 레이블과 일치해야 한다. 메타데이터만 고쳐 검사를 통과시키지 않는다.
- Python 하네스는 교안 코드를 실제 실행한다. 출처를 신뢰할 수 있는 교안에 사용한다.
- DNS 실제 응답은 시간과 접속 환경에 따라 달라질 수 있다. Windows 명령과 Packet Tracer 동작은 사용할 수업 환경에서 직접 확인한다.
- 그림은 macOS의 한글 글꼴로 확인했다. Windows·Linux 및 다른 글꼴의 실제 화면은 별도 확인이 필요하다. 글자 폭에 따라 줄바꿈과 배치를 조정한다.
- Notion 업로드와 저장 후 비교는 사용자의 Notion 연결에서 수행한다. 로컬 HTML 검수가 Notion에 저장된 결과의 검수를 대신하지 않는다.
