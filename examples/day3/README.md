# DNS 교안 예제

원본 노션의 인증 정보·페이지 ID·업로드 ID를 제거하고 로컬 그림을 참조하도록 만든 실행 예제다. 조직명·주소·서버명은 수업용 가상 설정이다. 공개 도메인 조회 값은 시점과 환경에 따라 달라진다.

| 파일 | 주제 |
| --- | --- |
| `lesson1.json` | 인트라넷·서버 역할, 이름과 IP, DNS 조회 |
| `lesson2.json` | DNS 계층과 조회를 이어가는 주체 |
| `lesson3.json` | 레코드, 캐시, TTL, 응답과 로그 |
| `lesson4.json` | 정상 DNS 실습 구성 |
| `lesson5.json` | DNS 응답 변경과 접속 대상 추적 |
| `lesson6.json` | 장애 판단과 분석 보고서 |

실습은 Cisco Packet Tracer를 사용하는 예다. 프로그램 자체와 실습 프로젝트 파일은 포함하지 않았다. 그림은 실제 화면 캡처가 아니라 교안 설정을 설명하는 구성도다. 스위치 한 대와 라우터 한 대, VLAN 10/20, DNS·웹 서버의 관계를 동일한 배치에서 추적한다.

`assets/`에는 PNG·SVG 19쌍이 있다. 저장소 루트에서 `python tools/check_examples.py`를 실행하면 `build/day3/`에 로컬 미리보기가 생긴다. 그림을 다시 그리는 명령은 저장소 README를 참고한다.

2026-09-06에는 설명의 깊이를 유지하면서 6개 교시의 절과 목차를 재구성했다. 이름 조회와 웹 접속, 원본과 캐시, 값 관찰과 판단을 각각 구분하고 관련 예외는 보충으로 옮겼다. 기존 코드·명령 예제와 그림을 유지했으며, 필수 용어 170개의 순서를 다시 검사했다. 결과와 검수 범위는 [검수 기록](../../docs/validation.md)에 있다.

4교시에서는 학생이 정상 구성을 `day03_dns_normal.pkt`로 저장한다. 5교시에 시작 파일이 없으면 현재 교안의 접힌 준비 절차로 기본 구성을 만들 수 있다. `.pkt` 파일이 저장소에 제공된다는 뜻은 아니다. 5교시 복구 후에는 정상 A 값을 확인하고 비교 실습 결과를 `day03_dns_response_comparison.pkt`로 저장한다.
