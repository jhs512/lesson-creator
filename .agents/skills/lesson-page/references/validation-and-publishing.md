# 검증과 Notion 반영

읽기 검수에서는 비유·사례를 통한 이해가 전문 명칭 나열보다 앞서는지 확인한다. 보충으로 옮긴 용어를 본문 그림이나 필수 질문에서 여전히 요구하면 먼저 고친다. `.com`과 `.com TLD 서버`처럼 관련된 이름이라도 역할이 새로 추가되면 필요한 설명을 생략하지 않는다. 명칭을 어려워 보인다는 이유만으로 `learning_terms`에서 지워 검사를 피하지 않는다.

아래 도구 경로는 `lesson-authoring-toolkit` 저장소 루트를 기준으로 한다. 실제 스키마 형식과 지원 옵션은 해당 도구의 문서·`--help`를 확인한다. 전체 저장소 없이 스킬만 설치했다면 먼저 함께 사용할 도구 위치를 확인한다.

## 원본과 검사

1. **JSON 초안**: `tools/lesson_schema.py`의 문서와 `examples/day3/lesson1.json` 등을 참고한다. `lesson_role`로 교시의 역할을 선언한다. `numbered_list`, `code`, `command`, `tool_steps`, `image`, 관찰 과제를 지원한다. 새 용어는 `learning_terms`, 이미지의 실제 글자는 `text_content`로 기록한다.
2. **스키마 검증·렌더**: `python3 tools/lesson_render.py path/to/lesson.json path/to/lesson.md`를 실행한다. 구조 오류를 고친다. 과제 번호·토글·파일명 서식은 렌더러에 맡긴다.
3. **하네스**: `python3 tools/lesson_harness.py path/to/lesson.json`을 실행한다. FAIL을 해결하고 모든 SKIP과 REVIEW의 이유를 검토한다. REVIEW는 목차 불일치·동일한 긴 설명의 반복·기본 설명보다 앞선 보충을 가리키는 검토 위치다. 수정하거나 반복·배치가 필요한 이유를 남긴다.
4. **린트**: `python3 tools/lesson_lint.py path/to/lesson.md --role concept`처럼 원본에 선언한 역할을 전달한다. 기존에 역할이 없는 교안은 이전 명령을 사용한다. ERROR를 해결하고 WARN은 교과·수업 형식에 맞춰 판정한 이유를 남긴다.
5. **읽기·시각 검수**: 렌더된 교안과 이미지를 `tools/judge_checklist.md`로 리뷰한다. 내용이 많으면 작성자와 다른 검수자를 활용한다. 용어 누락·정의 속 미설명 용어·선행 지식·상태 전환·과제 완결성·그림의 정확성을 확인한다.

하네스는 대상 Python 코드를 실행해 출력을 대조한다. 실습 입력 파일은 `fixtures`로 제공한다. `verified=measured`는 실제 실행으로 확인한 출력에 쓰고, 재현하지 못한 네트워크·Windows·실기기·LLM 출력은 `verified=example`과 예시임을 밝히는 `output_label`을 쓴다. 자동 실행되지 않은 명령·GUI 절차를 실측 검증했다고 보고하지 않는다. 실제 환경에서 확인할 수 있는 항목은 확인하고 결과를 별도로 기록한다.

하네스는 보안 격리 도구가 아니다. 자신의 검토한 교육용 코드에 사용하고, 출처를 모르는 코드를 실행하는 검사는 격리된 환경에서 진행한다. 검사 도구가 `input()`에 기본 응답을 보내는 경우 외부 변경이 발생하지 않는 예제인지 먼저 확인한다.

용어 검사 PASS는 선언한 목록과 실제 표시 순서에 관한 결과다. 앞 교시에서 설명한 개념을 다시 정의하지 않았다는 이유만으로 보강을 요구하지 않는다. 이번에 새로 도입하는 용어와 확인된 선행 개념을 구분하고, 선행 학습의 근거는 읽기 검수에서 확인한다. 같은 문단의 문장 순서, 정의의 쉬움, 목록에 빠진 용어는 저지가 확인한다. 뜻을 이해하지 못해도 문자만 맞추면 통과하는 형식 검사가 되지 않게 한다.

`supplement`의 본문·코드·그림도 용어와 출력 검사를 받는다. 하네스는 보충을 제외한 필수 본문을 한 번 더 읽어, 필수 용어의 설명이 보충에만 들어 있으면 FAIL로 처리한다. 보충에서만 쓰는 용어는 그 안에서 소개할 수 있다. 검사에 맞추려고 필수 용어·별칭·그림 글자를 삭제하지 않는다.

설명의 의미상 중복, 갑작스러운 주제 전환, 절 목표의 혼재, 예제와 해설의 분리, 미등록 용어와 어려운 정의는 자동 검사로 판정하지 않는다. 저지의 흐름·위계 검수에서 근거 문장과 수정안을 남긴다. REVIEW 0도 설명 품질의 통과 판정은 아니다. 구조 검사는 구름·번개·지그재그 등의 기호 자체를 풀이한 산문도 REVIEW로 표시한다. 이는 자동 삭제 지시가 아니다. 눈으로 알 수 있는 묘사는 덜어내고, 목적지·상태 변화·실패 이유 같은 기술 설명은 유지하도록 판정한다.

로컬 HTML 미리보기가 필요하면 `python3 tools/render_lesson_preview.py path/to/lesson.md path/to/preview.html`을 사용한다. 생성 완료만으로 렌더 검수를 대신하지 않고 브라우저에서 글·토글·그림을 확인한다. 입력 Markdown의 이미지 경로가 미리보기 위치에서도 열리는지 확인한다.

## 기존 교안을 부분 수정할 때

실제 저장된 교안을 먼저 가져와 수정 위치를 정한다. 원본 JSON이 있으면 같은 수정을 적용해 다음 재생성에서 사라지지 않게 한다. 해당 변경의 스키마·하네스·린트와 읽기 검수를 수행한다. 원본이 없으면 실제 가져온 문서에 대한 린트·읽기 검수를 하고, JSON 검증을 수행한 것처럼 보고하지 않는다.

새 설명을 붙인 뒤 목차·절 나눔·실습 준비·정답까지 다시 읽는다. 오류를 만드는 도구나 검사 누락이 발견되면 원인을 고친다. 객관적으로 확인 가능한 구조 위반은 스키마·린터·하네스와 적절한 회귀 테스트에 반영하고, 판단이 필요한 설명 품질은 저지 지침에 반영한다. 한 교안의 특수 사례를 무관한 수업의 일률적인 제한으로 만들지 않는다.

## Notion 반영

이 저장소는 Notion 자동 게시기나 인증 정보를 제공하지 않는다. 사용자의 연결된 Notion MCP·앱 기능을 사용한다. 수정 대상이 정해졌으면 그 범위 안에서 진행한다. 대상이 불분명할 때도 로컬 교안과 검사 결과는 먼저 준비한다.

1. 현재 페이지를 fetch해 제목, 본문, 하위 페이지, 이미지와 토글 구조를 확인한다. 신규 수업은 실제 과정 구조에서 원하는 위치를 찾는다. 예제에 있던 페이지 ID를 재사용하지 않는다.
2. 부분 수정은 실제 가져온 텍스트를 기준으로 `old_str`·`new_str`를 만든다. UTF-8 한글 원문으로 `[{"old_str": "...", "new_str": "..."}]` 형태의 파일을 작성하고 `python3 tools/mkedit.py path/to/edits.json`으로 도구 인자를 만든다. Unicode 이스케이프를 손으로 작성하지 않는다. 도구가 인코딩한 결과는 그대로 사용한다.
3. 이미지 변경은 사용자 환경의 업로드 기능으로 실제 이미지 블록을 만들고 캡션을 넣는다. 만료되는 이미지 URL을 포함한 긴 문자열 전체는 부분 수정의 안정적인 기준이 되지 않으므로 본문 앵커나 도구가 제공하는 블록 식별자를 사용한다.
4. 전체 본문 교체가 필요한 경우 하위 페이지 참조와 유지할 내용을 빠뜨리지 않는다. Notion 확장 Markdown의 `<page url="...">` 같은 실제 참조를 보존한다.
5. 반영 후 다시 fetch한다. 저장된 content를 파일로 남겨 린트를 다시 실행하고, 수정 본문·제목·토글·과제·정답·이미지 수와 위치·캡션·주변 설명이 의도대로 남았는지 확인한다.

Notion 저장 형식은 연결 도구에 따라 달라질 수 있다. 코드 언어의 `text`/`plain text`, 자동 링크, 밑줄 이스케이프, 탭을 원문과 대조한다. 토글을 Markdown으로 보낼 때 `<details>`, `<summary>제목</summary>`, 본문, `</details>`는 각각 다른 줄에 두고 본문은 탭으로 들여쓴다. 코드 블록에 언어를 지정하고 파일명은 백틱으로 감싼다. 현재 도구가 다른 입력 형식을 요구하면 그 형식을 따른다.

최종 보고는 생성한 교안·그림, 실제 실행한 검사, 검증하지 못한 환경 항목, 게시한 페이지를 구분한다. 로컬 미리보기만 만들었으면 Notion 반영 완료라고 쓰지 않는다.
